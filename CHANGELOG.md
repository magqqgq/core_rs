# Changelog

All notable changes to this project are documented in this file.

## [0.2.0] - 2026-06-01

### Changed

- Moved the canonical repository to [coinbase/core_rs](https://github.com/coinbase/core_rs).
- Added GitHub Actions CI and crates.io trusted publishing for releases.

### Notes

- No intentional API breaking changes; minor version bump signals the repository migration.

## [0.1.3] - 2026-06-01

### Changed

- Marked the `coinbase-samples/core_rs` repository as deprecated in the README.
- Documented migration to [coinbase/core_rs](https://github.com/coinbase/core_rs) and `core_rs` 0.2.0+ on crates.io.

### Notes

- Includes dependency updates and header error handling improvements merged since 0.1.2.

## [0.1.2] - 2026-05-22

### Changed

- Dependency updates.
- Return errors when HTTP header construction fails.

## [0.1.1] - 2026-05-19

### Changed

- Patch release with packaging and metadata updates.

## [0.1.0] - 2025-09-16

### Added

- Initial release on crates.io.
